# borvux.github.io (Jekyll Version)

This repository hosts the code for my personal portfolio website, built with Jekyll. It showcases my skills, projects, and work experience.

**View Live Portfolio:** [https://borvux.github.io/](https://borvux.github.io/)

## About This Portfolio

This is a static website generated using Jekyll, a simple, blog-aware, static site generator. It's designed to be easily maintainable and deployable on GitHub Pages. The styling incorporates Tailwind CSS alongside custom CSS.

## Deployment

This site is configured for deployment on GitHub Pages. GitHub Pages natively supports Jekyll.
